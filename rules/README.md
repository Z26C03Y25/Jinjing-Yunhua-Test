# 自定义规则（待 Ubuntu 引擎实测）

SID 1000001：规范化 URI 中先后出现 UNION 与 SELECT，间隔不超过 32 字节。不是 SQL 解析器，存在合法搜索误报和混淆绕过。

SID 1000002：URI 中出现 `<script`；不覆盖所有 XSS 上下文。

SID 1000003：原始 URI 包含 `/etc/passwd`，编码可以绕过；不证明文件读取成功。

SID 1000004：同源 SYN 高频检测，仅为扫描线索，不区分高频正常连接，慢扫可能漏检。

SID 1000005：DNS 查询长度超过 100 字节，仅是异常线索；合法长域名可能误报。

所有规则必须通过实际引擎 `suricata -T` 和正负样本回放后再认定有效，当前不声明检出率。
