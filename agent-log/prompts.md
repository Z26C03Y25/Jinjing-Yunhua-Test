## P5：只暴露 80

目标：公网单入口。约束：Nginx 代理、前后端内部网络。验收：浏览器通过公网 80 访问，后端无发布端口。结果已由用户截图和容器端口列表确认，有效。

## P6：停止旧 Compose

目标：部署前下架旧服务。约束：保留数据卷。验收：日志展示 down 再 up，原有任务保留。实现并远程验证，有效。

## P7：镜像手动准备

目标：避免脚本在慢镜像源无限等待。约束：用户先下载基础镜像。验收：脚本缺镜像退出，不先停服务。后续按用户要求增加缓存构建，而非完全禁止构建，有效但需随最终范围更新说明。

## P8：一次统一密码

目标：只输入一次相同的密钥口令/服务器密码。约束：不写入仓库。验收：后续推送和 SSH 无需重复输入。实现临时 askpass，修复中文路径错误后用户及 Agent 实测通过，有效。

目标：至少十次有意义提交、跨两天。约束：不能凑数或伪造日期。验收：真实代码/测试里程碑的 Git 历史。当前跨 2026-10-28/29 且超过十次，仍按实际开发提交，有效。
