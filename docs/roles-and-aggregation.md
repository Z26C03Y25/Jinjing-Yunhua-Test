# 角色与聚合

服务器 `.env` 可设置独立的 `VIEWER_PASSWORD`，启用用户名 viewer 的只读账号；留空时禁用该账号。分析员仍使用 analyst / APP_PASSWORD。两个角色均可读告警、任务、详情、规则和统计，viewer 的所有 POST 在后端拒绝，不能依赖前端隐藏按钮作为授权措施。

聚合 API `/api/groups?task_id=任务ID&window=10`：按任务、SID、五元组和固定 UTC 时间桶分组，窗口 1–3600 秒可配。返回 raw_count/group_count/reduction_rate，保留全部原始事件。不同阶段的不同 SID 不合并；相邻时间桶边界的重复告警可能分为两组，这是固定桶的已知限制。单任务最多聚合五万条，界面最多展示前两百组，计数基于完整任务。

这不是跨任务抑制，也不删除数据库中的原始告警。当前多个 SYN 的目标端口不同，因此按五元组不会合并，这是预期行为。

本地已验证分组边界。角色授权及新 API 还需在部署后验证；未设置 viewer 密码时不能声称只读账号已启用。
