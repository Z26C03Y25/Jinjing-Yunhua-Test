## 使用约束

仅允许修改仓库已有SID的单行alert规则；现已支持网页新增、归档删除和恢复（本节初版限制已更新），不支持Lua及文件落盘关键字。校验成功不证明规则检测效果正确，需要PCAP回放。版本标识属于应用审计版本，不自动修改规则文本中的rev。

当前操作人记录为共享角色analyst，尚非企业个人身份认证。规则基线来自仓库，应用历史保存在数据卷；生产环境还需要个人账号、TLS、备份恢复演练、资源容量管理和系统漏洞审计。
