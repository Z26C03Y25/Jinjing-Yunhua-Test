## 统计口径与缺陷

原始告警精确率与期望级召回率分别报告，不将重复正确告警减去期望 TP 后误算成 FP。finding 级 F1 使用期望命中项和误报分组，具体定义见 report.json。完成耗时含客户端网络、排队和轮询，不等同引擎首攻击包到入库时延。历史 pcap 的时间与当前墙钟不能直接相减作为性能指标。

聚合按 SID、五元组、任务和固定时间桶，不跨阶段合并，原始证据保留。本轮原始 2353 条告警聚合为 1156 组，减少约 50.87%；原始事件保留。首攻击包至入库的历史墙钟差与实际完成耗时已分开记录。正常 DNS 仅查询、TLS 仅 ClientHello，协议覆盖有限。HTTP 401 高频只是爆破线索，合法认证重试也可能误报。
