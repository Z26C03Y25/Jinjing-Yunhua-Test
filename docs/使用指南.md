# 使用指南（交付版）

## 登录与模块

打开系统，选择“分析员”或“只读用户”并输入密码。侧边栏划分运行总览、流量检测、告警研判、规则管理。退出清除内存凭据和已加载数据；刷新需重新登录。密码来自部署时生成的.env，不随源代码提交。

## 上传与检测

在“流量检测”选择经典PCAP并开始检测，单文件24字节至20MiB。等待“检测完成”后点击“查看告警”。queued是排队、running是执行、failed需根据错误排查。正常样本可能没有告警，不是系统失败。PCAPNG当前不支持。

首次体验使用data/web_sqli.pcap；负样本使用data/benign_mix.pcap。每个任务保存独立PCAP、EVE、日志和规则快照，避免结果串入其他任务。

## 告警研判

列表展示时间、源与目的IP/端口、协议、签名、等级和处置状态，支持来源/等级/状态筛选、排序和分页。点击“详情”，再点“加载完整详情”查询规则、原始事件、关联流量和审计。

详情右上角切换管理概览与专业研判。管理视图以中文解释说明谁访问谁、为什么提醒；专业视图保留技术证据与人工结论编辑。点击“查看原始记录”可在任一视图打开EVE原文。HTTP摘要会标注其不是原始payload；不能把EVE JSON称为完整逐包十六进制报文。

确认依据后设置新告警、已确认、误报或忽略。专业视图填写人工结论和处置建议并保存，修订追加留痕。导出管理风险简报或专业报告，内容基于最新保存记录。规则命中不证明入侵成功。

“聚合视图”按任务、SID、五元组和10秒固定桶分组，保留原始告警。API支持window=1至3600秒；不同SID、通信双方或任务不会被合并。

## 规则管理

上方按名称/SID和状态搜索，重置清空条件。工具栏提供新增、修改、删除；修改或删除先选中一条记录，也可使用行内快捷按钮。每页10条。

新增填写规则名称和单行Suricata检测条件，后台自动分配SID，名称写入签名。不要手填SID；原文中已有数字SID按系统新编号替换。名称不能代替检测逻辑。真实引擎校验通过才保存，失败保留输入供修正。

修改通过“校验并发布新版本”提交，SID保持不变。旧页面覆盖新版本会返回冲突，需要刷新核对。历史和回滚在弹窗内查看；回滚生成新版本，不删除旧历史。

删除需确认，实际采用归档：不再进入后续检测，保留编号、历史与任务快照。勾选“显示已归档规则”可恢复；恢复也需引擎校验，沿用原启停状态。归档版本不能直接修改。只读用户不能写入。

启停或修改对随后开始执行的任务生效，运行中及历史任务不变。演示停用后务必恢复再评测。

## 启动、评测、运维

Ubuntu首次运行make up；make validate启动并回放全部九场景，输出validation/report.json和report.md。独立空卷验收使用scripts/acceptance.sh，不删除业务数据。Windows同步部署用scripts\sync-remote.cmd -Deploy -GitHubSshPort 443。

备份与恢复、安全边界及故障处理见交付与运维.md。不要使用docker compose down -v清理日常业务。507表示空间不足，429可能是队列满或登录失败限流。重新启动时未完成任务标记失败，需要重传。
