# 规则 CRUD 验收（2026-10-30）

已部署功能版本7059f75。后端12项测试通过，真实Chrome及Suricata十项验收通过，机器结果为validation/rule-crud-smoke.json。

实际流程：非法关键字新增被引擎拒绝且未保存；浏览器新增合法规则；重复SID拒绝；浏览器编辑发布；旧版本归档请求拒绝；上传SQLi PCAP，新规则真实产生告警；浏览器归档后默认列表消失；旧告警仍显示任务内rev:2规则快照；勾选归档列表并恢复成功；审计历史包含create/edit/archive/restore。测试结束再次归档测试规则，不影响后续基线检测。

删除是可恢复归档，不是物理擦除。规则内容和版本存于SQLite持久卷，库备份覆盖这些数据；没有删除历史任务证据。归档规则不能直接编辑或启用；恢复需真实校验，通过后沿用原启停状态。SID永久保留，避免把历史告警关联到另一个规则。

权限：分析员可新增、修改、归档、恢复；只读角色所有写接口403。校验失败不写库，编辑、归档及恢复使用base_revision防止旧页面覆盖新内容。运行中任务不受更新影响。
