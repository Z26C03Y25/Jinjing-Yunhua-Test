# 录制与文档收尾计划

日期：2026-11-01。目标：5–8分钟连续录制，展示启动、真实回放、研判和自验结果。建议成片7分钟，不剪辑、不加速、不用旧截图代替执行。

## 录制前准备（不计入成片）

- 预留约30分钟准备、15分钟彩排、10分钟正式录制、10分钟检查。
- 使用独立目录、独立Compose项目和空数据卷，保留现有演示站点。演示环境仅绑定本机18080，通过SSH转发访问；正式录制前需实际配置并彩排此环境。
- 基础镜像可以提前缓存，但开场明确“空容器、空业务数据，基础镜像已有缓存”，不能说成无缓存新服务器。
- 预先配置独立环境密码，不展示.env、SSH密钥、密码管理器、终端历史中的凭据。bootstrap首次生成密码会打印，必须提前完成凭据配置。
- 准备data/web_sqli.pcap、benign_mix.pcap；规则保持默认启用，关闭其他无关窗口、通知和聊天。
- 浏览器与终端并排，1080p录制，字体放大到能看清；密码输入不录入明文。先确认录音正常。

若启动或评测较慢，压缩规则操作段，仍保留真实等待和最终报告。超过8分钟就排查原因后重新录制，不拼接成片。彩排先验证整套流程能在目标时长内完成。
