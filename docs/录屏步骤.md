# 5–8 分钟不剪辑录屏建议

1. 展示环境和仓库版本，说明测试环境与镜像缓存情况。
2. 从空容器环境运行 make up，展示启动日志和健康状态；不要删除仍需保留的业务数据卷。最终空数据复验建议使用独立测试环境。
3. 浏览器登录，上传自建 SQLi pcap，等待 complete 并展示告警与规则原文、原始事件、关联 flow。
4. 修改处置状态，展示审计记录；演示筛选和分页。
5. 关闭规则，重新检测，展示规则对新任务真实生效，随后恢复。
6. 运行 make validate，展示报告及慢扫 FN，说明正常样本与变异场景。
7. 说明最大缺陷、实际工时和后续改进。最终录屏必须由真实运行产生，不剪辑、不用预填结果代替。
